## Descripción

Proyecto desarrollado en Flutter que contiene seis ejercicios prácticos de formularios y validaciones.

## Ejercicios desarrollados

1. Formulario de nombres.
2. Formulario de correo electrónico.
3. Registro de edad.
4. Registro de DNI.
5. Registro de contraseña.
6. Formulario de estudiante.

## Tecnologías utilizadas

- Flutter
- Dart
- Material Design
- Formularios y validaciones

## Archivo principal

`lib/main.dart`

## Objetivo

Aplicar formularios, validaciones de datos y mensajes de confirmación mediante Flutter.
